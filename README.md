# Text-to-Image-Generator
This is a simple web application using JavaScript programming, that allows users to generate images from text prompts using a machine learning model hosted on the Hugging Face API. The app fetches images based on the user's input text and displays the generated image.

**Demo** 
https://text2imggen.netlify.app/

**Workflow**
- The user enters a text description (e.g., "a cat playing with a ball") into the input field.
- The user clicks the "Generate Image" button.
- The query function is called, sending the text description to Hugging Face's API.
- The API returns a generated image based on the description.
- The image is displayed in the img element on the page.
- The user can clear the input field and image by clicking the "Clear" button.

**Features**
- Input a text prompt and generate an image using the Hugging Face Text-to-Image model.
- A button to clear both the input and the generated image.
- Real-time loading image while the query is being processed.

**Technologies Used**
1. HTML for the structure of the web page.
2. CSS for styling.
3. JavaScript for dynamic functionality and API integration.
4. Hugging Face API for generating images from text.


**API Information**
Hugging Face API: The app utilizes the Hugging Face Text-to-Image API to generate images based on the user's text input.
API Documentation: For more information on how to use the API, refer to Hugging Face Inference API Documentation.
 
Link: https://huggingface.co/
